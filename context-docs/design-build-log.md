# DESIGN-BUILD-LOG.md

Granular, per-change log for the **V2 (Figma) redesign** — [figma.com/design/tkwjjcqSB2aWc5Cmjxd4gV](https://www.figma.com/design/tkwjjcqSB2aWc5Cmjxd4gV/UnLecture).

**Update this file after every change made during a session** (one row per change/instruction). `BUILDLOG.md` gets a single rolled-up summary entry only when a session ends — this file is the detailed record underneath it.

All V2 work is gated behind `lib/flags.ts` (`SITE_VERSION`). V1 (the original live site) is never touched by anything in this log — `/old` always shows it for reference regardless of the flag.
