# BUILDLOG.md

**Project:** unLecture
**Version:** v0.14.1

## Current Status

The Figma redesign is complete and is now simply **the site** — the old V1 design (and the `lib/flags.ts` `SITE_VERSION` toggle that used to switch between them) was deleted outright once V2 covered every page. The DB layer and `/admin` weren't touched by any of this — they're version-agnostic.

Site, top to bottom: Nav (no box/border, sits on page bg; Home/Events left, Articles/Contact right; mobile replaces the link groups with a MENU pill opening a full-screen overlay), Hero (poster carousel, exact Figma card sizing/gaps/gradient/arrow placement, mobile crops side-card peeks with no arrows), "How We Gather" (wavy dark section; desktop shows 4 real-photo ticket cards with exact stagger + doodles, mobile is a separate single-card auto-advancing carousel with arrows), "The Manifesto (About Us)" (heading + bordered/backgrounded text block, two-line heading on mobile), "As Seen In" (wavy dark section, infinite logo marquee; mobile is dedicated markup, not the desktop layout repositioned), "Newsletter" (solid-maroon section with bottom wave edge), Footer (single row, copyright + Email/Instagram/Linkedin links; centered/stacked on mobile). Standalone pages: `/contact`, `/events` (archive/listing), `/articles` (listing) and `/articles/[slug]` (detail, self-hosted Ancizar Serif body copy) — all four have their own dedicated mobile layouts now, built against exact Figma nodes with real uploaded mobile assets.

Testimonials and Ticker were dropped in the V1 deletion — no V2 replacement exists yet, and whether they're still wanted hasn't been confirmed.

Desktop is scaled to fit uniformly (CSS `zoom`) between the 1400px reflow breakpoint and the 1920px design canvas, so nothing clips on in-between desktop widths without needing separate layout work. Mobile (`<=900px`, matched consistently across every section after a couple of early breakpoint-mismatch bugs) now has a complete, purpose-built layout for every page — not just a shrunk desktop.

All context docs live under `context-docs/` and all `public/` asset folders follow lowercase-kebab-case naming (`custom-assets/`, `wavy-shapes/`, `card-shapes/`, `news-features-logo/`, `category-covers/`, etc.) — see the 2026-09-13 entries in `design-build-log.md` for the full before/after mapping if a path looks unfamiliar. `design.md`'s spacing/sizing tables were retired in favor of `developer-updated.md` — the mobile build introduced a lot of one-off, Figma-node-specific pixel values that don't form a reusable system, and the site's near-term direction (an open-canvas, relatively-positioned layout) means one isn't being forced prematurely either. Colors and fonts, which *are* still a real shared system, stay documented in `design.md`.

Granular per-change history lives in `design-build-log.md` (updated after every change); this file gets a summary entry at the end of each session.
